F · UGS Analytics EventsThe event stream (UGS-only)

Everything routes through AnalyticsServiceFacade (P1 shipped 2026-06-11, P2 shipped 2026-06-15 — single writer, DI singleton, owns StartDataCollection). SDK batches automatically — Flush() only on app pause/quit. Each event + its parameters must be declared in the UGS dashboard Event Manager — full list of constants in UGSKeys.cs. Full event-by-event detail: INSTRUMENTATION_DATA.html.
