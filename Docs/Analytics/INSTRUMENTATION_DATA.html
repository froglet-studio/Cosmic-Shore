How the events above actually ship. Full detail in Docs/Analytics/DATA_INVENTORY.md §3–4.

Build order (VSlice):
0. Retire the Firebase analytics path — port ui_action + ad_impression to UGS, delete the dead collectors (decision: UGS for everything)
1. UGS Analytics event facade (SOAP-driven, replaces the dead Firebase collectors — reuse their event taxonomy)

Then (VDemo): training migration, captain re-enable → pilot events, episode funnel (flag IAP dependency), telemetry extensions + style tag.
