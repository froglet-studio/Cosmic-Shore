Rev 113 notes: Voyages Milestone 1Escort the Ark and Crystal Run made good end to end. Numbers from the Milestone 1 game plan. Awaiting a pick per board.
Lobby (recommended)

The lobby is the only page: you, then friends who join, then AI wingmates. No Squad 1 / Squad 2 tabs. A saved squad is one line (Y) that fills the open AI seats and never your seat or a friend's. "Flies this voyage" on your card and "You sail as Manta · Space" by Set sail are read from the record the voyage spawns from, so the bug where a pick did not apply shows here.

Picker

One press on a vessel saves it to your seat for this voyage (not to a squad preset), and the line under the grid says so. Vessels that suit an escort carry "For this voyage"; every vessel stays pickable.

Crew

The six stacked recommendation cards over the map become one button, "Crew recommends · 8", that opens this popup. Escort the Ark and Crystal Run are open (Crystal Run is offered whoever is seated, so it sits above the factions). Every other crew voyage shows its pilot, job and difficulty under its faction, locked for Milestone 1. Factions shown are examples.

Hud

The objective box holds what is true now: the goal in the voyage's own words, the five worlds as stops, the hull with the breach line for the chosen difficulty, the Ark's state and time to the next world, and one action line. Fauna on the Ark carry a red marker, and an edge arrow when off screen.

Run

The crystal counter leads (12 / 20), counted from the start of the leg, with the split by element under it (any element counts). Each cell on the route is marked calm or hostile before you reach it, so the player chooses: farm the hostile cell or stay with the Ark.

Toasts (Compare)

A few seconds each, top centre, one at a time; colour by kind (an event, a threat, a goal). Wording follows the game plan.

Score

The Ark's hull at the core against the breach line, a row per seat, then rewards: the escort pays crystals scaled by difficulty. Finish (B) banks and returns to Voyages; Venture further (A) runs the same escort one difficulty up. Crystal Run uses the same board with crystals per element per seat; a lost Ark shows it as failed with Try again.
