Rev 128 notesGame cards, six ways
Asked (Shombith, 2026-11-23)“Redesign the arcade/ arena game cards. Currently they are still images ... They need to get way way better in terms of lets say appearance, motion, hover features etc. They need to lively yet not affect performance.”One mode, Skim Race, drawn seven ways: the card we ship (Rev 18 A, section 73, hover 101.1 Sheen) and six new ones, same size (341 x 296), same words.Today the card is one still render (the /cardart offline render of the mode’s arena) that drifts 5 px over 40 s.
What each costs in UnityA Depth. Three images in the card’s mask; a tilt and three offsets set on pointer enter / move, eased. Nothing per frame at rest but the drift and five motes (one shader).B Racing line. One line mesh on the band with a scrolling material (the comet is a UV offset, like CardDrift). The hull tween plays once on hover. The line per mode comes from the course /cardart already renders.C Hero hull. The hull image moves outside the mask; a bob on the existing PortraitBob shader; one tween on hover.D Silver foil. One overlay material on the band (a scrolling gradient), a tilt like A. The cheapest of the moving ones.E Poster. One height tween on hover. Nothing moves at rest but the drift.F Live loop. A 3 s flipbook (24 frames in one atlas per mode) played only on the hovered or focused card; every other card shows its first frame. Costs memory per mode, not frame time.
Rules every option keepsHover is white; the pad’s focus is the sky-blue ring, and focus plays the same as hover, so a controller sees the motion too.Touch gets no hover: on a phone the card is the rest state, and a press opens Configure as today.Locked cards stand still and answer nothing.Elements have no colour: the shape stays white. The only colour is the render itself (and the trail prisms in F, as the game draws them).At most one loop per card at rest; F has none.The words are each card’s own (SO_ArcadeGame: name, Description, players). Joust’s Description is still the placeholder “Joust joust joust”, which E would show.
Recommendation: B, Racing lineIt teaches the mode at a glance (skim the trail, through the rings, to the crystal), so the card says what the game is without a word.It is lively at rest at almost no cost (one scrolling line per card), and the Squirrel flying it on hover is the payoff.It grows to every mode: each card’s course comes from the generator /cardart renders, so the line is data, not hand art.Mix and match is open: B’s line works with C’s hull or E’s slide-open body.
