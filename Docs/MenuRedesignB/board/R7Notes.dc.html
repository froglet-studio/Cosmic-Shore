Rev 7: playtest round
Selection
One glowing blue for whatever is selected or focused: a bright sweep runs round the border and the glow breathes. Built once in the kit (the tile, button and tab selection states plus the nav underline), so every screen changes together. The sweep and glow animate in a shader, so they cost no canvas rebuilds.
AI difficulty
The configure already has the AI row (EASY / MEDIUM / HARD, host picks, guests see it), but it only shows on the 7 modes whose AI reads it (Skim Race, Slingshot, Warpline, Regatta, Astro League, Brood Rush, Broadside). To show it on every mode with AI seats, the platform autopilot's difficulty (Yash's Arena AI difficulty: the AI notices late and sometimes misjudges on Easy / Medium; Hard is today's AI) would be switched on for the other modes. That changes how those AIs fly at the default (Medium).
LT / RT between windows
Inside Toy Box, Arcade, Arena or Mission, LT / RT (and arrows on the screen edges for mouse and touch) slide to the neighbouring window in the Home hub's order. The configure keeps LT / RT off.
Friend profile
Hover or focus an online friend's avatar (party seats, the online list, the orb's members) and a card pops beside it: avatar, name, FRIEND / ONLINE, where they are (in the menu, in a lobby n / 4, in a match and which game), what they fly, and JOIN / INVITE / WATCH / ADD FRIEND. Stats like level or wins are not readable for other players today (no public profile record), so they are not on the card.
Loading screen
Changing cell shows the lattice, the cell's name, an omni crystal filling with the build, the four build steps and a tip. The screen runs at the build's frame rate (about 10 FPS while prisms are laid), so the motion is slow and large on purpose.
