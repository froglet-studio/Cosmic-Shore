Rev 11 - backgrounds

What goes: the line lattice behind every window and panel today (Lattice_Window / Lattice_Panel). Seen up close it reads as a grid.

Option 1 - Amoebius's lattice: the launcher's LATTICE background, as Amoebius draws it: pointy-top hexagons (radius 34 at 1080p) and one bright ring rippling out from the centre about every 5 s. It is drawn here in the menu's blues (SurfaceLight lines, a light-blue ring). Amoebius itself draws it violet to cyan, but violet is close to an element colour, which the new colour rules keep out of the UI.

Option 2 - see-through glass (you asked for the transparency back; the solid surfaces at the bottom are kept only for comparison): G clear veil + lattice, H frosted glass, I edge veil, J hex stained glass, K tide glass, L current glass. Full screens: Arcade (G), Toy Box (H), Profile (I + tide). The world behind is a rendered Broadside arena, the busiest scene we have.

How it would be built in Unity: one UI shader per background (like today's lattice shader, animated by time alone, so it never re-draws the canvas), a material per option, and the window generators swap the backdrop material. The panel version is the same shader at lower alpha.

Note on Garrett's attention rule: he asked that nothing move for its own sake. Every option here is slow, low contrast and sits behind opaque panels. If he objects, each one also has a still frame.
