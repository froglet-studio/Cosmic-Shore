Upright

Home, turned upright and back. The scene behind the UI (the cell) keeps drawing; only the UI goes out and comes back, so the turn reads as the UI re-forming over a live world, never as a cut.

Built as OrientationFade on Menu_Main's canvas root, with its own CanvasGroup: alpha 0 on the frame the layout switches (AdaptiveCanvasScaler.PortraitLayoutChanging), 2 frames held while the PC blocks fitted to the width re-fit, then 0 to 1 over 0.28 s on OutCubic. Taps wait until it is back.

The same on every screen: Home, Arcade, Configure, Hangar re-flow; the rest is the PC layout fitted to the width.

The loop on the right plays the turn both ways; Slow x4 shows the hold and the fade.
