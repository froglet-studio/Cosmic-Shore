Asked"Only thing the hypersea map and the bottom edge on view should stay apart from that ... delete the old voyages mockups and create new" (Shombith, 2026-11-12, on the built Rev 81 B5 and Rev 83 S2).
Kept, in all threeThe course on the HyperSea and the same course seen edge on under it, as Rev 81 drew them.
New, in all threeFour tabs as the game has them (Voyages, Saga, Quests, Episodes). No seat editor screen: a seat changes where it stands, and the map is never covered. One Lime: Set sail. Jade marks the pick.
A Slide (recommended)Small voyage cards on their own water; the picked one slides open with its words and numbers. The right column is only the squad: a row per seat, and a pressed row opens Vessel, Pilot, Element and Artifact as four steppers.
B Wide seaThe whole course picture, uncropped, takes the left of the window with its edge view under it. One panel on the right: the four voyages, the open one's numbers, the squad's three hulls in formation, and a tray of tiles under a pressed seat.
C TicketThe quietest: a list of places with no pictures, and the open voyage as one ticket. The crew are three lines; a pressed line opens the same steppers; Set sail is the ticket's stub.
For the buildEach is made of pieces the menu kit already has (a plate, a text tab, a stepper, a card), so it can be authored as prefabs rather than built in code at runtime, which is what kept the last build from updating.
