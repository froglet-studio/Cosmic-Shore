Rev 42 notes - three looks for the Silver Screen console
Asked. "I feel the console app can look better" (Shombith, 2026-11-01), after the Silver Screen theme (his site's look: black and white like a film still, poster headings, typewriter labels) and the film stills behind each view.
A · Marquee (recommended). Each view opens on a full-width still of the game with the title set in it, as a film poster does; the stat tiles overlap the still's bottom edge and the lists follow. Same dark ground, same type, same lists as the built page: only the top of each view changes, so the build is a stylesheet change and one hero block per view. Recommended because it gives the pages the cinema the theme promises without touching a single row.
B · Poster cards. No hero; every card wears its own still as a 96 px band with the card's title set over it, and the stat tiles become posters with the number set large. More picture per screen, at the cost of every card needing a still that fits it; a page with eight cards is eight pictures.
C · Ledger. The light edition: paper grey, ink type, the stills as thin 40 px bands under each card's title, rows 56 px, tiles smaller. For people who read the console in daylight; it is the light theme the built page already has, made deliberate.
What stays in all three. The sidebar, the top bar with New run, the lists and tables, the Silver Screen type (Bebas Neue, Space Mono, Inter for rows), the one cyan accent, the status colours. No idle motion but the Starting bar.
The data. The live console's of 2026-11-01 (three computers, 13 searches, 332 races). Compare shows the Home page's top in A, B and C side by side at the same scale.
