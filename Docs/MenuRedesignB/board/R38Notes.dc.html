Rev 38 notes - the Compute console as an application
Asked. "The artifact and the UI is noisy make it look like an application." References picked: "Go with Tailscale and Linear, plus Optuna for searches."
What changes. A fixed left sidebar and a 56 px top bar replace the website-style header and its gradient headings. Lists and tables replace cards. Status is a dot and a word, as in Tailscale's machine list; each computer's actions live in its row menu (Send a run, Start now, Stop, Copy name), not a button on every card. One accent colour, used only for the primary action and live data. No explanatory paragraphs on the pages; the tour and the notes carry the explanation.
Searches. Optuna's study view: a list on the left, the picked search on the right with its optimization history (best score after each try, today's AI as a dashed line), the settings it found against today's, and race time per intensity. Approve sits in the panel's header.
Kinds of work. Every run carries one small tag with a coloured dot: Offline model (a computer searches the race model, no Unity), Unity · AI vs AI (a computer plays the real game with no window), Played by a person (a race in the Unity editor, which the hourly sweep learns from).
The data. Every number here is the console's snapshot of 2026-10-29 (two computers, 13 searches, 233 recorded races); nothing is invented.
Not the game's kit. This is a team tool, not a game screen: it uses an app kit (Inter, a neutral dark ground, the game's Jade cyan as its one accent) instead of the menu's Aldrich and Chakra Petch. Light theme follows the system in the build. No idle motion, no glows.
