The switch row is the one piece every other board uses, so it would come first. Colour: a split wears Jade, Ruby, Gold, Blue in that order with a legend, so colour is never the only cue; play types keep Rev 65's Jade solo vs AI, Gold solo, Ruby multiplayer; unsplit data is Blue; a heat or map is one hue. On a board where colour means a build or a player, play types are words. Red is only a fault (an alert, a worse number); Lime only a better one. No player id reaches Claude on any of these.
