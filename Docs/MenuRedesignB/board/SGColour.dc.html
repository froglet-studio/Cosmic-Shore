1 · Colour

Six families, one meaning each

Garrett's colour chart (#1664) decides which family a colour belongs to, with a forbidden band between families. Jade is what you can change again, Ruby is what you cannot take back, Lime is always the call to action. A colour that means nothing is Blue. Elements carry no colour.

Lime

Call to action, always
cta#99FF80

Use for The important thing to do now: launch, join, accept, claim; online, a done tick

Never for Headings, eyebrows, decoration, a choice you can change

Fire

Danger
danger#FF4B3A

Use for Delete my data, a guest-account warning, why a game cannot launch, connection lost

Never for Anything merely important

Gold

Spend, and the Gold domain
purchase#FFAE00
Gold domain#FFA700

Use for A purchase, an upgrade, any button that uses a resource; the crystal glyph

Never for First place, a highlight, a reward amount

Jade

Pick, change again
Jade domain#0EC0B6
selection / control#00D4FF

Use for A choice you can claim and reclaim: a hull pick in an arena mode, friends, the selected thing, the focus ring; toggles and sliders; Team 1

Never for An element, a commitment

Ruby

No way back
Ruby domain#C800C3
commit#A600FF

Use for A commitment you cannot take back: the Ready button; Team 2

Never for An element, a choice you can change

Blue

Neutral, and every grey
text#E6E9FF
text-soft#747BAD
surface#222645

Use for Text, panels, lines, structure, information

Never for A call to action, a selection
