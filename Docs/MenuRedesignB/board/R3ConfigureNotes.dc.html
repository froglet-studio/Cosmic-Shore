Configure: pick one (or mix)
A - Cinematic
The live preview fills the whole window and is the first thing you see; tap anywhere on it to fly. Every setting sits on one console along the bottom (vessel, intensity 1-4, pilots by domain, START). Briefing / Controls / Objective are tabs in a side panel. Most immersive; least room for long briefings.
B - Step cards
A wide live-preview banner with the briefing over it, then three tall step cards - 01 Vessel (with its controls), 02 Intensity (with the objective), 03 Pilots - in the same rhythm as the Profile quest cards. Reads top to bottom, very clear for a first-timer; the preview is shorter.
C - Split console
Left: a big preview (about the size it is today, 1040 x 600) with Briefing / Controls / Objective as tabs under it. Right: a plain settings list - Vessel, Intensity, Domain, Pilots - one row each, no tree diagram. Calmest and easiest on a pad (straight up / down).
Kept in every option
Everything the window does today: live preview + tap to fly, objective counter and +1, vessel set by the card, intensity lock, domain choice, AI seats, party seats, leaderboard on weekly cards, START / waiting for others, B to go back.
