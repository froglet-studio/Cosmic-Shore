Asked (Shombith, 2026-11-06): filters and sorting on Players; "different analytical tools like pie charts, gantt charts etc for business development" instead of lists; the data in named eras ("Old Posthog data", "Pre Beta Editor testing results", on "a plan chart"); a solo vs AI / multiplayer filter; "the best analytical tool ever"; "give control to admins more like creating new tables queries". Seven screens of one tool, not seven options: pick the ones to build, or change any. Drawn in the console's default theme, Nocturne, with the sea lines; every number is sample data.

Charts: categories wear the colour set's four rims in a fixed order (Jade solo vs AI, Gold solo, Ruby multiplayer; Blue for plain data), each with a legend and labels, so colour is never the only cue; the game's rims are brighter than the usual chart band, so labels stay on. A donut is used only for one whole in three parts; anything with more parts is ranked bars. Lifespans and the match timeline are Gantt charts on a time axis. A sequential heatmap is one hue, light to dark.
