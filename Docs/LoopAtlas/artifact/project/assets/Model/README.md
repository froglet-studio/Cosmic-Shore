The atlas as data, for agents and tools. `nodes` are the loops above the kit (`in` says which layers: n now, p planned, x proposed; `t` is one pass in seconds; `reps` is passes before stepping up; `at` is the step of the parent it opens). `edges` are trains, crossings and feeds. `fleet` is every vessel's kit, games, board marks and combos. `roles` are the Role loops by kind of Round. Read `tiers` first.
