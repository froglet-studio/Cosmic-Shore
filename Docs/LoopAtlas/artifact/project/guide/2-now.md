## Holes

| Loop | What is missing |
|---|---|
| The long game | How many sittings make one pass, and how often a person comes back, is not measured. Analytics events are declared but no funnel reads them yet. |
| A sitting | Nothing in the game points a player from one place to another. A crossing happens only if the player opens Home and thinks of it. |
| A sitting | Rounds per sitting and places per sitting are not measured. |
| Toybox | What a toy session is for, in loop terms, is not written: there is no stated reason to leave a toy or to come back to one. |
| Arcade | Rounds per run are not measured, and nothing but the player's own wish moves them from a card to the next card. |
| Arcade | Most cards have never been played: steps 1 to 3 of the elemental loop are 'built', not 'done', for every vessel and element except Dolphin Time step 1. |
| Mass-Space game | Only the category has landed. The per-vessel merge has not started: the board still shows Mass and Space as two games each. |
| Arena | Matches per set, and what makes a squad stay for another, are not written. |
| Astro League | The plan names three arena games. Where Astro League sits (a fourth arena, or an arena-sized party game) is not said. |
| A voyage | It is not said whether voyage pay is the same crystals that buy vessels, so the step from 'voyage ends' to 'spend it on a vessel' has no confirmed path. |
| A cell | Cells per leg is not set. |
| A cell | Whether 'take the cell, the Ark regrows, move on' is the built loop or the intended one needs one editor run to confirm. |
| Activation | No player has seen the onboarding. The first loop a stranger meets is an unlocked menu. |
| The quest chain | The chain orders 4 cards. About 80 others have no order, so after the Hangar opens nothing says what to play next. |
| The fleet | Crystals buy only vessels. When the fleet is owned the reward has no use, and the payout stops driving anything. |
| The fleet | Which of the 23 hulls ship, at what price and in what order, is not decided beyond the first five. |
| A saga | A saga does not run again, so four sagas are a fixed amount of story. 'A season could reseed it' is a default, not a decision. |
| Party and friends | Nothing a party does together lasts past the sitting, so a friend is a reason to play tonight and not a reason to return. |
| Replays | A replay cannot leave the device, so it drives mastery and nothing else. |
| Episodes | What an episode gives the player is not defined in loop terms: it opens no loop on this map. |
