Studio agent

Ask about a vessel

Ask for a design idea, a new play-style type, or what a number does. The answer comes from Claude with the studio's numbers in hand.

Development requests

File a change for a studio or a vessel. A Claude Code session, or Prisma's AGENT page, reads this list and does the work on the vessel-studio branch.

Every studio is a reader of the game's shipped numbers, never their authority: each page names the asset it copied a value from. Plan and platform notes: Docs/Studios/VESSEL_STUDIO_PLAN.md.
