# Placeholder sounds: what Charles makes first

Generated by `python3 Tools/Build/sound_placeholders.py --write-md` from [`sound_placeholders.json`](sound_placeholders.json); edit the JSON, never this page.

Every empty vessel sound slot (and the race, menu and payload slots beside them) now plays a **recycled placeholder**: an event already in the banks, chosen to fit the act (Garrett, 2026-11-16). That is **239 sounds over 323 slots**. Each sound below has a **target** event path. Nothing in the game points at the target yet. The same list as a page to share, with search and copy buttons: https://claude.ai/artifact/TvjtZ42i2fwHMNF1x1tMPc (rebuilt from this ledger).

**How to replace one (no Unity work):**

1. In FMOD Studio, create the event at the target path (right-click the placeholder event > **Duplicate** is a quick start; keep it a loop or a one-shot as listed). Assign it to the `SFX` bank.
2. Build the banks and commit `Cosmic Shore/` as usual.
3. Run `python3 Tools/Build/sound_placeholders.py --promote` (or ask any Claude session to): every slot still on the placeholder moves to your event. `--check` tells you which targets are ready.

Loops must stay loops and one-shots one-shots (the code starts and stops a loop; a one-shot is fired and forgotten). Parameters the code drives are listed where they matter. A sound names the act and the element, never the team (`SOUND_LANGUAGE.md`).
