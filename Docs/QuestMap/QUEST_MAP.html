One system — how the graph drives everything

Quest Graph (source of truth)→ CTA breadcrumbs· GameModeProgressionService (unlocks / intensity)· Dialogue system· UGS cloud save (per node)

While a quest is running, the graph owns guidance (the service’s auto-breadcrumb is suppressed). Gates listen to the progression service’s own events, so intensity tiers and claims stay exactly as the quest-track UI shows them. Every completed node is recorded per player in UGS — resume lands mid-phase, and the funnel shows where players drop off.
