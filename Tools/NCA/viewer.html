A lizard grown from one cell

Every pixel below runs the same 8,336-parameter rule, sees only its 3×3 neighbours, and fires at random half the time. Starting from a single live cell, the rule grows the Noto lizard emoji. This is a CPU PyTorch reproduction of Mordvintsev et al., Distill 2020, running live in your browser.
